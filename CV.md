## Selected Projects

### [SQL MCP Server](https://github.com/alam1704/sql-mcp)

Built a C#/.NET 8 Model Context Protocol server that gives GitHub Copilot
read-only access to SQL Server metadata. The server can discover online
databases and select a target database per request for table and column
inspection across the same server while keeping credentials in environment
configuration and avoiding arbitrary SQL execution.

**Technologies:** C#, .NET 8, Model Context Protocol, Microsoft.Data.SqlClient,
SQL Server, GitHub Copilot CLI
